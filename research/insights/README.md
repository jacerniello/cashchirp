# insights/

*What we believe.* The durable end of the pipeline: notes on market mechanics, catalyst
groups, and methods that survived being tested.

An insight earns its place by having a run behind it. Something that only ever sounded
right belongs in a log entry marked *inconclusive*, not here — the whole value of this
folder is that its contents were checked.

## Conventions

- Lead with a one-paragraph TL;DR.
- Separate **method** (reusable) from **example** (illustrative). The method outlives the
  example: *"comparing against the eligible universe rather than the index removed most of
  the apparent edge"* stays true; *"quality-value worked 2011–2016"* ages badly.
- Tag the **catalyst / reasoning group** so insights cluster.
- Cite sources inline as markdown links so claims are traceable.
- Flag what is *verified* vs *commonly-repeated* — market lore is noisy.
- Link the log entry that produced it, and cross-link related notes with `[[name]]`.
- Prefer numbers, dates and tickers over vibes.
